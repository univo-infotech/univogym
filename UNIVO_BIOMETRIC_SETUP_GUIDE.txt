1. OVERVIEW & ARCHITECTURE (System Kaise Kaam Karta Hai)
================================================================================

Univo Gym ka Biometric System 100% automated hai:
1. Member gate par machine ke sensor par ungli (fingerprint) lagata hai.
2. Machine punch signal software ko bhejti hai.
3. Univo Gym 0.1 second ke andar 4 security checks karta hai:
   - Kya member ka plan valid hai? (Expiry date check)
   - Kya fees baaki (Due balance) toh nahi hai?
   - Kya member account 'Left' ya terminated toh nahi hai?
   - Kya gym owner ne member ko manually gate lock toh nahi kiya?
4. Faisla (Decision):
   - Sab kuch OK hai  -> 🟢 ACCESS GRANTED! (Attendance lag gayi, streak badh gayi, gate open)
   - Fees pending hai -> 🛑 ACCESS DENIED! (Gate lock rehta hai, buzzer bajta hai)

2. STEP 1: MACHINE KO NETWORK / WI-FI SE CONNECT KARNA (Sirf Ek Baar Karna Hai)
================================================================================

1. Machine ko power adapter se ON karein aur peeche LAN cable lagayein ya Wi-Fi connect karein.
2. Machine par "M/OK" button 2-3 second daba kar Main Menu kholein.
3. "SetComm" (ya Comm.) -> "Ethernet" (ya Wi-Fi) me jayein:
   - "1. DHCP" ko "Yes" (ON) karein.
   - Neeche "OK" dabakar Save karein.
   - Router machine ko automatic IP de dega (Jaise: 192.168.1.9).
4. Phir "SetComm" -> "Server Set" me jayein:
   - "1. DNS": "No" (Local testing ke liye) ya "Yes" (Jab online domain ho).
   - "2. Server IP": Computer ki IP (Jaise: 192.168.1.5).
   - "3. SerPortNo": 7005 (Secureye standard port).
   - "OK" dabakar Save kar dein.
5. Result: Machine router aur computer ke saath 100% connect ho gayi!

7. SPECIAL SCENARIOS (Gym Ke Real-World Sawaal Aur Unka Hal)
================================================================================

Q1. Member ki fees khatam ho gayi, kya mujhe machine se uska thumb delete karna padega?
Ans: KABHI NAHI! Machine me kuch delete nahi karna padta. Software automatic usko
     "ACCESS DENIED" kar dega. Machine buzzer bajayegi aur gate open nahi hoga.

Q2. Member ne fees de di, gate wapas kab khulega?
Ans: Jaise hi aap software me "Collect Fee / Renew Plan" karoge, agle hi second
     uska gate automatic UNLOCK ho jayega!

Q3. Agar kisi member ne gym me jhagda kiya ya use temporary ban karna ho?
Ans: Software me "Member Biometric IDs" tab me jakar uske aage "🔒 Lock Gate"
     daba dein. Uska gate access turant band ho jayega. Jab problem solve ho jaye,
     "🔓 Unlock Gate" daba dein.

Q4. Agar gym me internet chala jaye toh?
Ans: Biometric machine ke paas apni internal storage hoti hai (1,00,000 punches).
     Jaise hi internet wapas aayega, saare punches automatic sync ho jayenge.
     Ya fir bina internet ke bhi USB Pen Drive laga kar "U-Flash -> Download GLog"
     karke software me 1 click me upload kar sakte hain.

Q5. Agar gym me 2 gates hain (Entry Gate aur Exit Gate)?
Ans: Dono machines ko software me register kiya ja sakta hai (Hardware Setup tab).
     Member kisi bhi gate par punch karega, software track karega:
     "Aman Verma - Entry at Main Gate (06:00 AM)"
     "Aman Verma - Exit at Gate 2 (07:30 AM)".
