# Univo Gym Management

**Stronger Today, Healthier Tomorrow**

A comprehensive gym management platform built with React + Vite + Firebase.

## Features
- Multi-role access: Owner, Trainer, Member
- Member self-registration via WhatsApp link (5-min expiry)
- Digital liability waiver with signature
- Membership plan management
- Payment tracking (Cash/Online/Bank/Mixed)
- Equipment stock & service reminders
- Daily/Monthly/Custom reports
- WhatsApp broadcast notifications
- Visits & Demo management
- Before/After progress gallery

## Tech Stack
- React 18 + Vite + JSX
- Firebase (Auth + Firestore + Storage)
- Tailwind CSS
- Recharts
- jsPDF

## Setup
```bash
npm install
npm run dev
```

## Environment
Copy `.env.example` to `.env` and fill in Firebase config.
